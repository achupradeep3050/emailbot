Privacy policy

Last updated: 30 October 2026

Hermes Emailbot ("the app") is a private assistant operated by Achu Pradeep for his own Google accounts. This policy explains what the app does with Google user data.

Data the app accesses

With the account owner's consent (Google OAuth, scope gmail.modify), the app reads the owner's Gmail messages and labels. It changes a message only when the owner asks it to from Telegram: mark as read, archive, apply a label, save a draft, or send a reply the owner has approved. It never deletes mail.

How the data is used

  • To decide which new messages are important, and to write a short summary of those for the owner.
  • To show the owner a message, or a draft reply, in the owner's private Telegram chat with the app's bot.

To classify and summarise a message, the sender, subject and an excerpt of the text are sent to a large-language-model API (xAI) that processes it on the owner's behalf. Nothing is sold, used for advertising, or shared with anyone else.

Storage and security

The app runs on the owner's own computer. The OAuth tokens and a small local database (message IDs, sender, subject, the importance decision and the summary) are stored there with owner-only file permissions. Full message bodies are not kept. Notifications go only to the owner's Telegram account.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Removing it stops the app, and the local data can then be deleted by the owner.
